# TechBridge

A responsive landing page for TechBridge by Baselink Services Limited. The page introduces the learning programs and practical internship, explains how to apply, and provides community and contact links.

## Project files

- `index.html` — page content and inline SVG illustrations/icons
- `style.css` — responsive layout, styling, and animations
- `images/` — TechBridge logo assets

## Run locally

No build step or dependencies are required. Open `index.html` directly in a browser, or serve the project directory with any static file server, for example:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
